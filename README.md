## Engineering approach

- Start with a small, explicit architecture and document its trade-offs.
- Treat tests, health checks, migrations, observability, and rollback as product features.
- Prefer least privilege, pinned dependencies, reproducible local environments, and automated security checks.
- Write runbooks for failure modes instead of assuming the happy path.
- Keep examples local and free to run whenever a cloud account is not essential.
